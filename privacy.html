Privacy Policy – Matematik Post

Last updated: 30 October 2026

Matematik Post is a personal publishing tool run by the owner of the Matematikte Özgürleş accounts. It prepares short math-question videos and posts them to the owner's own Instagram, Facebook, YouTube and TikTok accounts. Only the owner signs in to it; it is not offered to other users. The sections below describe, for each platform, what it accesses, what it stores and how to remove access.

YouTube API Services

Matematik Post uses the YouTube API Services to upload videos to the owner's YouTube channel. By using Matematik Post you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What information it accesses and how it is used

  • Upload permission (youtube.upload): used only to upload the owner's own math videos, with a title and description, to the owner's channel.
  • Read permission (youtube.readonly): used only to read the channel's name, to confirm that the connection works.

It does not read, collect or analyse comments, viewers, subscribers, statistics or any information about other people, and it does not use YouTube data for advertising.

What is stored, and where

The only YouTube data stored is the sign-in key (an OAuth refresh token) and the ID of each uploaded video. Both are kept in a file on the owner's own computer; nothing is stored on a server. Matematik Post does not use cookies or similar tracking technologies.

Sharing

No data is sold, shared with or transferred to any third party. Data obtained through Google APIs is used in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access and deleting data

Access can be removed at any time on the Google security settings page: security.google.com/settings/security/permissions. When access is removed, or on request to the contact address below, the stored key and video IDs are deleted from the computer within 7 days. Videos already on YouTube stay on the channel until the owner deletes them in YouTube Studio.

TikTok

Matematik Post uses TikTok's Login Kit and Content Posting API to post the owner's own math videos to the owner's own TikTok account. Use of TikTok is also subject to the TikTok Terms of Service and the TikTok Privacy Policy.

  • user.info.basic: used only to read the account's display name and open ID, to confirm which account is connected.
  • video.publish and video.upload: used only to upload the owner's own video with its caption and post it to the owner's profile, and to check that the post went through.

It does not read followers, comments, other users' videos or any other information. The only TikTok data stored is the access and refresh tokens, the open ID and the ID of each post, kept in a file on the owner's own computer and never shared. Access can be removed at any time in the TikTok app under Settings and privacy → Security → Manage app permissions; the stored tokens are then deleted from the computer within 7 days, or on request to the contact address below.

Instagram and Facebook

Matematik Post uses Meta's Instagram and Facebook Graph APIs to publish the owner's own posts and Reels to the owner's own Instagram account and Facebook Page. It reads only the account name, the Page name and the status of its own posts, so that nothing is posted twice. The Page access token is kept on the owner's computer and never shared. Use of these platforms is also subject to Meta's Terms of Service and Privacy Policy. Access can be removed in Facebook under Settings → Business integrations.

Changes and contact

Changes to this policy are published on this page with a new date. Questions or deletion requests: matematikteozgurles@gmail.com.
